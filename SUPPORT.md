# Support

transom is an **early-preview (alpha)** hobby-scale project. Support is best effort, with no response-time guarantee and no promise that
a given issue will be fixed.

- **Platform:** Windows 11 only (developed on build 10.0.26300). Other versions are unsupported.
- **Bugs and feature ideas:** open a GitHub issue using the templates. Include the Windows build, the transom commit, what you did, and
  what you expected. Screenshots are helpful.
- **Never paste** logs, configuration backups or usage data without removing media titles, application names, paths and tokens
  (see [PRIVACY.md](PRIVACY.md)).
- **Security problems:** do not use public issues; see [SECURITY.md](SECURITY.md).
- **Questions about how it works:** the (Slovak) design and verification notes are in [docs/PLAN.md](docs/PLAN.md); the README lists the
  known limitations.
- There are no binary releases or installers yet; build from source as described in the README.
