# transom

Plnosirkova horna lista (AppBar) pre Windows 11, napisana v Ruste. Stav: rane vyvojove fazy, pozri `docs/PLAN.md`.

- `crates/transom-core` - bez Win32: model stavovych poloziek, rozlozenie, politika vyberu medii, bateria, casova funkcia posuvneho textu (`marquee`).
- `crates/transom-platform` - Win32: AppBar, monitory, DPI, napajanie, simulacia skratiek (Win+S/Win+B), procesy, vrstvene okno pre priehladne pozadie (`layered`).
- `crates/transom-render` - rozhranie `Painter`, temy, scena; backend R0 (GDI).
- `crates/transom-media` - GSMTC sluzba (media session) na vlastnom MTA vlakne.
- `crates/transom-config` - konfiguracia (verzovany JSON `%APPDATA%\transom\config.json`, migracia, atomicky zapis).
- `crates/transom-i18n` - preklady (`locales/*.txt`; sk, en, cs, de, fr, es, pl, it, pt, ja, zh-Hans; zaloha na anglictinu). Okrem sk a en nerevidovane.
- `crates/transom-usage` - vyuzitie AI (Claude Code, Codex) z lokalnych zdrojov, cennik s datumom, suhrny, limity planu
  (5 h / 7 dni len zo zaznamu nastroja, nikdy z cien; v liste kruhovy indikator).
- `crates/transom-peripherals` - baterie periferii (len citanie): Bluetooth z Windows, Razer, Logitech HID++ 2.0, NuPhy WH80;
  `cargo run -p transom-peripherals --example probe` precita zariadenia tohto PC.
- `crates/transom-app` - binar listy.
- `crates/transom-settings` - okno nastaveni (rozlozenie, hodiny a kalendar, AI a sukromie); spusta sa z ponuky na pravom tlacidle na prazdnom mieste listy.
- `crates/transom-statusline` - volitelny most pre `statusLine` Claude Code (pouzivatel ho nastavi sam).
- Priklady na overovanie: `cargo run -p transom-render --example preview -- <adresar>` (vzhlad pri 100/150/200 % bez zmeny DPI),
  `cargo run -p transom-platform --example msaa_probe` (pristupne nazvy lisaty z ineho procesu),
  `transom-settings --shot <adresar>` (offscreen audit okna nastavení: orezanie, prekryvy, kontrast; 11 jazykov × 96/144/192 DPI × 2 témy) a testy popoveru AI,
  `cargo run -p transom-render --example marquee_check` (orezanie posuvneho textu cez skutocne GDI pri 96/144/192 DPI),
  `cargo run -p transom-render --example alpha_check` (priehladne pozadie: alfa z dvoch prechodov proti priamemu vykresleniu).
- `tools/ticker-measure.ps1` - izolovane meranie posuvneho textu (plynulost snimok cez `--ticker-stats`, CPU) so simulovanym dlhym nazvom.
- `tools/` - pomocne skripty na overovanie (snimky lisaty a okna, klik vratane praveho tlacidla, kontextove menu, simulacia sprav, meranie CPU `cpu-sample.ps1`, podklad pod priehladnu listu `backdrop.ps1`).

Build: `cargo build --release`. Pravy klik na prazdne miesto listy (nie na ovladaci prvok) otvori vlastne temove menu: Settings / Customize bar (rovno stranka Layout) / AI usage / Hide bar / Quit transom (sipky, Home/End, Enter, Esc, pismeno; klik mimo ho zatvori); rovnake menu ma ikona v oblasti oznameni. Skrytu listu vrati ikona v oblasti oznameni alebo opatovne spustenie transom. Okno nastaveni ma vlastnu hlavicku (logo + nazov, minimalizovat / maximalizovat / zavriet, tahanie, dvojklik, snap, Alt+F4, Tab prechadza tlacidla hlavicky). `transom-settings --page layout|displays|media|appearance|clock|ai|language` otvori rovno danu stranku. Monitory: `cargo run -p transom-platform --example monitors`. Licencia: MIT.

Volitelny archiv dennych suctov (Nastavenia > AI a sukromie > Archiv dennej historie; predvolene VYPNUTY): uklada len denne sucty podla poskytovatela a modelu (tokeny, pocet volani, odhad ceny + datum cennika, priznak neuplneho dna) do `%LOCALAPPDATA%\transom\usage-archive.json`, aby mesacna historia prezila zmazanie logov poskytovatelov; nikdy prompty, odpovede, nazvy konverzacii ani projekty. Da sa pozastavit, nastavit retenciu (3/6/12/24 mesiacov alebo bez obmedzenia) a zmazat (s potvrdenim). `tools/archive-check.ps1` overi sucty proti nezavislemu vypoctu.

Export a import nastaveni (Nastavenia > Export a import; spolahlivo len lokalne, nic sa neposiela): **Exportovat nastavenia...** otvori systemovy dialog Ulozit a zapise subor `transom-settings-RRRR-MM-DD.json` (len rozlozenie lisaty, hodiny, posuvny nazov skladby, vzhlad, jazyk a interval/poskytovatel/rezim kruhu AI). **Nikdy** neobsahuje zapnutie zdrojov AI, archiv, rucne datumy, vyber monitorov, preferovanu aplikaciu medii, poverenia, cesty ani data o vyuziti. **Importovat nastavenia...** otvori dialog Otvorit, subor overi (najviac 256 KB, platny export transom, nie novsia verzia formatu) a ukaze **nahlad zmien** po sekciach so zaskrtavacimi polickami, zoznamom ignorovanych poloziek a neplatnych sekcii. Nic sa nezapise, kym nekliknete **Importovat vybrane** a nepotvrdite druhym klikom; **Zrusit** alebo Esc nahlad zahodi a nezmeni nic. Pred zapisom sa konfiguracia znova nacita (ak sa medzitym zmenila, nahlad treba potvrdit znova), kopia `config.json` sa ulozi do `%APPDATA%\transom\backups\` (poslednych 5; zalohy obsahuju aj prepinace zdrojov AI, preto ich mazte rucne, ak ich nechcete) a zapis je atomicky so zachovanim suberznych zmien. Import **nikdy** nezapne zdroje AI ani archiv. Ak je konfiguracia poskodena alebo z novsej verzie (len na citanie), export aj import su vypnute. Subor z neduveryhodneho zdroja si pred importom pozrite v nahlade; import nevykonava ziadny kod.

Panel Zvuk a rychle akcie (polozka listy **Zvuk**, v Nastaveniach > Rozlozenie ju treba zobrazit; predvolene skryta): klik otvori kompaktny panel s predvolenym zariadenim na prehravanie, zoznamom vystupov (len na citanie; predvolene / vypnute / odpojene), **systemovou hlasitostou a stlmenim Windows** (Core Audio, aktualizovane z notifikacii bez pollingu; je to hlavna hlasitost predvoleneho vystupu, **oddelena** od zvukov rozhrania transom, ktore menia len relaciu transom) a rychlymi akciami (Rychle nastavenia Win+A, Oznamenia Win+N, Hladat Win+S, oblast oznameni Win+B, Nastavenia transom; vyber zobrazenych akcii: Nastavenia > Panel zvuku). **Co transom nerobi:** nemeni predvoleny vystup (Windows 11 na to nema podporovane verejne API a transom nepouziva nedokumentovane rozhrania); tlacidlo *Vybrat vystup vo Windows* (Win+Ctrl+V) a *Nastavenia zvuku* (ms-settings:sound) len otvoria povrch Windows a panel hlasi "poziadane, transom nevie potvrdit"; zmenu predvoleneho vystupu ohlasi az notifikacia Core Audio. Rychle akcie nic nepotvrdzuju (skratky Win+A / Win+N / Win+Ctrl+V su len klavesove skratky Windows a pri zvyseneho popredi sa zablokuju s oznamom). Zariadenie bez regulacie hlasitosti alebo stlmenia, ziadny aktivny vystup a nedostupna zvukova sluzba maju vlastny text. Nazvy ani ID zariadeni sa nelogu ani neexportuju; sluzba bezi len ked je polozka viditelna a nikdy pri testoch (`--secs`, `--test-*`, `--sim-*`). Zivy test hlasitosti (len na vyslovne spustenie, obnovi povodnu hlasitost a stlmenie): `cargo run -p transom-audio --example volume_check -- --live`.

Zvuky rozhrania (Nastavenia > Zvuky rozhrania; **predvolene vypnute**, nizka predvolena hlasitost 25 %): kratky, tichy a vygenerovany zvuk (ziadne externe subory) po **umyselnom a uspesnom** kliknuti na ovladac listy, polozku menu alebo ovladac popoveru. Nehra pri prechode mysou, vypnutych ovladacoch, neuspesnych akciach, aktualizaciach na pozadi, animaciach ani v automatickych testoch (`--test-*`, `--sim-*`, `--secs`, `--no-sound`, premenna `TRANSOM_NO_SOUND=1`). Zaskrtavacie policko (vypnute = stlmenie, plati hned) a posuvnik hlasitosti (0-100 %, sipky, Home/End) ovladaju **len samostatnu relaciu transom** v miesadle hlasitosti Windows ("transom UI sounds"); nikdy nemenia prehravanie medii, vyber vystupneho zariadenia, ine aplikacie ani hlavnu hlasitost Windows. Tlacidlo **Vyskusat** prehra zvuk pri zvolenej hlasitosti. Bez zvukoveho zariadenia sa zvuky ticho preskocia (lista sa nezdrzuje). Zivy test nezavislosti od systemu: `cargo run -p transom-sound --example session_check` (len cita hlavnu hlasitost a relacie inych aplikacii, prehra 3 velmi kratke ticho zvuky).

Panel AI (klik na polozku AI v liste): prepinac **Left | Used** (karty limitov aj kruh v liste; uklada sa do konfiguracie) a v karte historie zalozka **Month** - denne tokeny alebo odhad ceny (nie faktura, nie kvota planu) za zvoleny mesiac, filter poskytovatela, rozpis dna, oznacene dni bez historie / neuplne (tvar, nie farba). Historia je len taka dlha, ako lokalne zaznamy Claude Code (maze ich po `cleanupPeriodDays`, predvolene 30 dni) a Codex. `cargo run -p transom-app --example history_dump` vypise denne sucty a `tools/history-check.ps1` ich nezavisle prepocita.

Claude Code (limity planu): Nastavenia > AI a sukromie > **Pripojit Claude Code**. Tlacidlo zalohuje `~/.claude/settings.json` (alebo `CLAUDE_CONFIG_DIR`), pridá **len** kluc `statusLine` (zvysok suboru ostane bajt po bajte), overi vysledok a ponukne **Vratit spat**; cudzi `statusLine` sa bez vasho rozhodnutia nikdy neprepise. Prikaz pouziva lomky (`C:/.../transom-statusline.exe`), lebo Claude Code ho spusta cez Git Bash. Limity (`rate_limits`) posiela Claude Code len uctom claude.ai Pro/Max/Ultra a az po prvej odpovedi relacie; `statusLine` spusta Claude Code v **terminali**, pre zalozku Code v aplikacii Desktop to dokumentacia nepotvrdzuje. "Vyskusat pripojenie" spusti most s vymyslenym vzorkom (nic nezapisuje).

Konfiguracia: okno nastaveni alebo `config.json` (`TRANSOM_CONFIG` prepise cestu, `TRANSOM_DATA` adresar lokalnych dat).
Argumenty: `--theme light|dark|system`, `--height N`, `--monitors primary`,
`--media-app TEXT` (preferovana aplikacia pre media, podretazec AUMID, napr. `spotify`), `--no-media`,
`--log SUBOR`, `--ticker-stats` (diagnostika plynulosti posuvneho textu do logu), `--secs N` (ukoncenie po N s, na testy), `--sim-battery 57[,charging]` (**len test vzhladu**, simulovana bateria),
`--sim-media "Nazov[|paused]"` (**len test vzhladu**, simulovana media session na skusku posuvneho textu).
